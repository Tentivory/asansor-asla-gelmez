# ASANSÖR ASLA GELMEZ

> Resmi slogan: *Kapı açılacak... belki de açılmayacak. İkisi de bilimseldir.*

Bu depo, insanlığın en köklü altyapı sorununu çözmek için kurulmuştur: **asansörün gelmemesi**.

Çözümümüz radikaldir. Asansörü hiç getirmiyoruz. Böylece bekleyen kimse hayal kırıklığına uğramaz; çünkü beklenti, protokol tarafından daha baştan iptal edilmiştir.

## Neden bu kadar ciddi?

Çünkü şaka gibi duran şeyler resmi yazıldığında daha korkutucu olur. Bu proje:

- gerçekten çalışır
- gerçekten bir yere varmaz
- gerçekten Türkçe konuşur
- gerçekten merdiven önerir

## Kurulum

```bash
git clone https://github.com/Tentivory/asansor-asla-gelmez.git
cd asansor-asla-gelmez
python3 asansor.py
```

Python 3 yeter. Asansör belgesi, sigorta, yük taşıma ruhsatı **gerekmez**. Zaten yük taşımıyor.

## Kullanım senaryosu

1. Programı çalıştır.
2. Bir kat söyle. Örneğin `4` veya `mutluluk`.
3. Sistem düşünsün.
4. Sistem düşünmeye devam etsin.
5. Sen merdivene yönel.
